128 schemas, one per request and response, JSON Schema draft-06, with a
`$id` of the form `urn:OCPP:Cp:2:2020:3:<Message>Request|Response`.

OCA has not reissued them since 2020: the Edition 3 download
("OCPP 2.0.1 Edition 3 (all files & errata)") ships the same 128 files,
byte for byte. OCA's [ReadMe](../ReadMe.md) says the same: Edition 4
updated all documents except the schemas.

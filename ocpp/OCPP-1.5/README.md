# OCPP 1.5

Historical copy of the OCPP 1.5 specification (2012), its technical
description and its two WSDL files, superseded for over a decade. The files
are kept unmodified, with their notices, under the repository's
[archival policy](../../docs/third-party-assets.md#archival-policy); see
[the third-party assets inventory](../../docs/third-party-assets.md#ocpp-ocpp)
for the rights holders of each file.

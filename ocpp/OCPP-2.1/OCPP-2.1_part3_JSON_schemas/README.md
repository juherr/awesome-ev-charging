181 schemas, JSON Schema draft-06: one per request and response, with a
`$id` of the form `urn:OCPP:Cp:2:2025:1:<Message>Request|Response`, plus
`NotifyPeriodicEventStream.json`, which has no response and no suffix.

Edition 2 did not reissue them: the Edition 1 download
("OCPP 2.1 Edition 1 (all files & errata)") ships the same 181 files,
byte for byte.

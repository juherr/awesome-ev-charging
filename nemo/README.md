# NeMo documents

Every PDF the [NeMo project website](https://web.archive.org/web/20230205021136/https://nemo-emobility.eu/)
published under `wp-content/uploads/`, as indexed by the Wayback Machine
([CDX query](https://web.archive.org/cdx/search/cdx?url=nemo-emobility.eu/wp-content/uploads/*&filter=mimetype:application/pdf&collapse=urlkey)),
plus two Common Information Models editions found on the site but never archived.
The website itself answers HTTP 410, but every file below was still served
by `nemo-emobility.eu` on 2026-11-02.

The documents most relevant to EV charging interoperability are vendored in
this directory. Each name links to the original file; the date is its upload
folder, not the document date.

97 documents, 9 vendored.

# eMI³ documents

Every PDF the [eMI³ website](https://web.archive.org/web/20230925033629/http://emi3group.com/)
published under `wp-content/uploads/`, as indexed by the Wayback Machine
([CDX query](https://web.archive.org/cdx/search/cdx?url=emi3group.com&matchType=domain&filter=original:.*%5C.pdf.*)),
plus those its archived pages link to without a capture of the file itself, and
the 2015 uploads served from the site's CDN host (`wpengine.netdna-cdn.com`).
`emi3group.com` no longer answers, so the Wayback Machine is the only other source.

Several captures of the specifications stop at exactly 1 MiB and are truncated.
The *Archived* column links a capture checked complete; for the vendored
documents it is byte-identical to the copy in this directory. *Not archived*
means the Wayback Machine holds no copy of the file: only 404 responses, or
no capture at all.

16 documents, 6 vendored.
